# 数据留存与源码分发

`out/<login>/` 是运行时输出，不是随源码分发的示例资料。原始 JSONL 可能包含真实用户活动、仓库元数据和提交作者信息；画像、图表及模型提示词也可能反映这些数据。没有自动清理期限，运行者应决定保留期限、访问范围和删除方式。

本次候选修改从当前源码树移除两份按用户生成的 JSONL，保留现有 `out/` 忽略规则。这不会删除 Git 历史、已有 clone、归档包或第三方副本。不得描述为历史抹除。演示与测试使用明确的合成数据。

向外部模型发送提示词前应检查其中的内容。日志不应记录真实凭据。历史安全测试字面量的核对结果不能代替所有 Git 历史的审查。重新开放外部发布入口需要对最终发布 commit 单独核对。
